- **신청범위는 공식 지원대상 기준**: 시행기관 주소나 주택 소재지만 보고 지역을 결정하지 않습니다. 부산진구청·사하구청은 시행기관이며, 해당 구 주민 대상이라는 원문이 있어야 구 단위로 분류합니다.

## 3. 표준 파일은 어떻게 만들었나

`prepare_housing_2026-10-02.cjs`가 수집 자료와 수동으로 대조한 내용을 통합 파일로 내보냅니다. **조건 해석과 사업 선별이 모두 자동화된 것은 아닙니다.**

1. **기존 자료를 후보로 재검토** — 9월 29일 자료를 참고하되, 날짜·조건을 그대로 최신값으로 재사용하지 않고 10월 2일 공식 자료와 대조했습니다.
2. **API 후보와 추가 공식 자료 수집** — 주거 318건·교통 19건을 탐색하고 부산·구청·공공기관 자료로 보완했습니다.
3. **신청범위·사업 성격 검토** — 지원대상 지역, 전입·활동 인정, 개인 지원사업인지 개발·공급계획인지, 담당 세부분류에 해당하는지 확인했습니다.
4. **원문을 44컬럼에 분리** — 지원대상 원문을 별도로 보존하고 연령·거주·취업·학력·소득·특화·제외조건·금액·기간·신청방법을 각 열에 정리했습니다.
5. **사업·회차 중복 대조** — 정책명·시행기관·신청기간을 함께 확인하고 공식 원문을 우선했습니다. 여러 API 등록을 같은 사업의 행으로 연결하거나, 조건이 다른 유형을 별도 행으로 정리했습니다.
6. **예외 경로와 상태 기록** — 기본 연령과 대학생·취업준비생·병역·신혼부부 등의 경로를 분리하고, 확인한 신청기간으로 상태를 기록했습니다.

**318건 → 58행은 단순 필터 결과가 아닙니다.** 318건에는 같은 사업의 연도·구별 등록, 행정계획, 타지역 후보가 있고, 58행에는 API 밖에서 추가 조사한 사업과 유형별 분리 행도 있습니다. 따라서 `318－58=260건 제외`로 계산하면 안 됩니다.

## 5. '확인필요'는 왜 확인필요인가

### 통합 표의 진행상태 확인필요 — 35행

| 주요 사유 | 처리 방식 |
| --- | --- |
| 제도·상품 안내는 있지만 개별 접수기간을 확인하지 못함 | 사업 운영과 현재 신청 가능을 구분 |
| 단지·유형·순위별 모집이 다름 | 대표 제도에 특정 단지의 기간을 일괄 적용하지 않음 |

### 후보 판정에서 주의할 것

현재 **지역검토보류 237건**, 사업명·기관명 때문에 타지역 조건을 검토하는 후보 **11건**이 있습니다. 이들은 지역 코드나 이름만으로 신청 불가를 확정한 항목이 아닙니다. 화순 청년하우스 1건과 청년온가 3건은 전입예정 경로를 확인해 별도로 표시했습니다.

`조회 성공`, `검색 완료`, `조건 대조`, `최신성 확인`은 서로 다른 단계입니다. 최신성 미확정 291건을 전부 접속 불가로 설명할 수는 없습니다. 사업소개·동명 자료만 확보한 경우와 후속 회차 대조가 부족한 경우도 포함됩니다.
