# SRS v0.7 구현 점검표 (2026-11-22)

점검 방법: ① 앱을 실제로 띄워 테스트 계정으로 화면을 하나씩 열어 봄(목업 56장을 이 화면으로 교체하면서 확인), ② 코드·DB 스키마 확인, ③ 응답 시간 측정.
표시: ✔ 확인함 · △ 일부만 됨/확인 못 함 · ✘ 안 됨. **FR 139개·NFR 66개·유스케이스 37개를 모두 한 줄씩 시연한 것은 아니고**, 아래는 확인한 근거가 있는 항목이다. 팀원 담당(검색·지도·마이) 기능은 "화면이 열리고 핵심 동작이 되는지"까지만 봤다.

## 4. 유스케이스 확인

UC-COM-001~007, UC-SRCH-001~003, UC-MAP-001~010, UC-MY-001~008 모두 대응하는 화면이 열리는 것을 목업 교체 과정에서 확인했다(지도 UC-MAP-005 위치 권한 거부 안내, UC-MAP-006 찜한 장소, UC-MY-005~007 아이디·이메일·비밀번호 변경 화면 포함). 메일 인증이 필요한 단계(가입 완료, 이메일 변경 완료, 비밀번호 재설정 완료)와 알림이 실제로 쌓인 알림 센터는 시연 데이터가 없어 끝까지 실행하지 못했다.

## 5. 목업 교체

SRS 수정본의 6.2 목업 56장(UI-H/A/C/COM/SRCH/MAP/MY)을 현재 앱 화면(390×844, 2배 해상도)으로 교체했다. 메일 발송이 필요한 화면은 서버 응답을 흉내 낸 상태로 캡처했다(아이디 찾기 완료·미가입 안내, 비밀번호 찾기 인증·새 비밀번호). 알림 센터(17)는 시연 계정에 알림이 없어 빈 목록이다.
